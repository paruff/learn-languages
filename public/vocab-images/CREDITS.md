# Vocabulary Image Credits

Every file in this directory must have a row here before it's referenced from
content (`imageUrl` in a realisation's vocabulary item). This site is
published under CC-BY-4.0, so an image without a clear, checked license here
is a licensing liability, not just a missing credit.

## Accepted sources

Public domain or openly-licensed only. Good starting points: Wikimedia
Commons, Openverse (filter by CC0/public domain), Pexels/Unsplash
(free-to-use license, no attribution required but still record the source
here).

Do not add images from gated/authenticated platforms (course portals, paid
stock sites) regardless of whether you personally have access — this site's
CC-BY-4.0 license requires the content itself to be redistributable, which
access to view something does not establish.

## Format

- Square-ish images work best (rendered at 96×96 in the lesson vocabulary
  list — see `.vocab-item__image` in `[nodeId].astro`).
- Prefer `.webp` for size; `.jpg`/`.png` are fine too.
- Keep individual files small (a few KB to a few tens of KB) — these load on
  every visit to a lesson page.
