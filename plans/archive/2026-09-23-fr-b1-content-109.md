## Global Constraints

- Vocabulary item `id` format: `{lang}-{nodeId}-{SEQ}` (regex: `/^[a-z]{2}(-[A-Z]{2})?-.+-\d{3}$/`)
- `nodeId` format: `{LEVEL}-{SKILL}-{SEQ}` (regex: `/^(A1|A2|B1|B2|C1|C2)-[A-Z]+-\d{3}$/`)
- **Parity rule:** every fr-FR B1 realisation has exactly the same **vocabulary** count as its en-GB counterpart. **Measured baseline: en-GB B1 = 6 vocab items per file (all 18 files), 108 total** — spec §3's "7/8 items = 127" counted grammar-block ids (`B1-GRAMMAR-*`) too; vocabulary-only is what `checkVocabularyParity()` compares (`src/lib/contentIntegrity.ts:58`). Per-file match is the rule; it resolves to 6 everywhere for baseline files. Seq `{NNN}` carries the **same concept** in both languages (pairing joins on seq id suffix; the lessons page also pairs by array index)
- Field conventions for fr-FR files: `term` = French, `translation` = **English** gloss (en-GB's Portuguese glosses are stale — ignore them; mirror the en-GB `term`/`example` concepts), `example` = French, `exampleTranslation` = English, `gender` = French grammatical gender on nouns only (omit elsewhere, per `fr-FR/a1-greet-001.yaml`), `grammar: []` (target-language convention), `culturalNotes` = optional France-specific note only
- **Register:** natural **B1-register** French — connected discourse, justification, connectors (`parce que`, `mais`, `d'abord… ensuite`) where the inventory teaches them — not A2-level telegraphic phrases; noun–adjective agreement checked in every example
- **No new vocabulary images** — no en-GB B1 file has an `imageUrl`; add none (`docs/content-attribution.md` policy unchanged)
- **Decision rule (full expansion — spec §3):** reuse a B1 node when its `canDo` substantively covers the descriptor; otherwise **create** a new `B1-*` node when the descriptor is a real descriptor (not `Pas de descripteur disponible`), maps to a schema `skill` enum value, and models an assessable learner ability (same bar as A2, not A1's stricter filter); document `Pas` rows, strategy/meta statements, and non-modellable items (scripted performance / prepared auditoire, niche creative writing, formal-meeting acts) as explicit gaps. New nodes are created as **trios** (cefr-node + en-GB + fr-FR, 6 vocab items each, `grammar: []` on both realisations) in the same commit so parity stays green
- B1 descriptors map **only** against B1 nodes — never covered by an A1/A2 node. Substantial cross-level `canDo` duplication is noted as an observation in the docs; the B1 node is still created when the descriptor is uncovered at B1
- `npm run validate:content` must pass after every content task; vocabulary-parity warning nodes must stay at the current baseline of **17** (new warning nodes = regression)
- Run `npx prettier --write` on touched files before each commit (lefthook lint-staged enforces `prettier --check` on `src/**` YAML)
- Zero TypeScript source changes (`src/**/*.ts`, `src/**/*.astro`) are expected outside `tests/e2e/review-fr.spec.ts`
- **NG7 / playbook non-negotiable:** push a PR for human pedagogical review — do not merge this content yourself; PR body must flag **AI-authored language content — human pedagogical review required**

function enB1Terms(): Set<string> {
  const terms = new Set<string>();
  for (const f of readdirSync(EN_DIR)) {
    if (!f.startsWith('b1-') || !f.endsWith('.yaml')) continue;
    const text = readFileSync(join(EN_DIR, f), 'utf8');
    for (const m of text.matchAll(/^\s+term:\s*(.+)\s*$/gm)) {
      terms.add(m[1].replace(/^['"]/, '').replace(/['"]$/, ''));
    }
  }
  return terms;
}
