## Global Constraints

- Vocabulary item `id` format: `{lang}-{nodeId}-{SEQ}` (regex: `/^[a-z]{2}(-[A-Z]{2})?-.+-\d{3}$/`)
- `nodeId` format: `{LEVEL}-{SKILL}-{SEQ}` (regex: `/^(A1|A2|B1|B2|C1|C2)-[A-Z]+-\d{3}$/`)
- **Parity rule:** every fr-FR A2 realisation has exactly the same vocabulary count as its en-GB counterpart (baseline **6 items per file**), and seq `{NNN}` carries the **same concept** in both languages (pairing joins on seq id suffix; the lessons page also pairs by array index)
- Field conventions for fr-FR files: `term` = French, `translation` = **English** gloss (en-GB's Portuguese glosses are stale — ignore them; mirror the en-GB `term`/`example` concepts), `example` = French, `exampleTranslation` = English, `gender` = French grammatical gender on nouns only (omit elsewhere, per `fr-FR/a1-greet-001.yaml`), `grammar: []` (de-DE A2 precedent: targets ship empty grammar), `culturalNotes` = optional France-specific note
- **No new vocabulary images** — no en-GB A2 file has an `imageUrl`; add none (`docs/content-attribution.md` policy unchanged)
- **Decision rule (full expansion — spec §3):** reuse an A2 node when its `canDo` substantively covers the descriptor; otherwise **create** a new `A2-*` node when the descriptor is a real descriptor (not `Pas de descripteur disponible`), maps to a schema `skill` enum value, and models an assessable learner ability (lower bar than A1); document strategy/meta statements and `Pas` rows as explicit gaps. New nodes are created as **trios** (cefr-node + en-GB + fr-FR) in the same commit so parity stays green
- A2 descriptors map **only** against A2 nodes — never covered by an A1 node
- `npm run validate:content` must pass after every content task; vocabulary-parity warning nodes must stay ≤ the current baseline of **17** (new warning nodes = regression)
- Run `npx prettier --write` on touched files before each commit (lefthook lint-staged enforces `prettier --check` on `src/**` YAML)
- Zero TypeScript source changes (`src/**/*.ts`, `src/**/*.astro`) are expected outside `tests/e2e/review-fr.spec.ts`
- **NG7 / playbook non-negotiable:** push a PR for human pedagogical review — do not merge this content yourself

```typescript
import { readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { SESSION_SIZE } from '../../src/lib/reviewSession';

const JOB_LESSON_URL = '/learn-languages/en-GB/fr-FR/lessons/A2-JOB-001/';
const FR_DIR = 'src/content/realisations/fr-FR';
const EN_DIR = 'src/content/realisations/en-GB';

/** fr-FR vocab ids for a level (grammar blocks are empty in fr files, so every id is a vocab id). */
function frVocabIds(levelPrefix: 'a1-' | 'a2-'): string[] {
  return readdirSync(FR_DIR)
    .filter((f) => f.startsWith(levelPrefix) && f.endsWith('.yaml'))
    .flatMap((f) =>
      [...readFileSync(join(FR_DIR, f), 'utf8').matchAll(/^\s+- id: (fr-FR-\S+)\s*$/gm)].map(
        (m) => m[1]
      )
    );
}

/** en-GB A2 terms — the expected vocabulary surface of any A2 session card front. */
function enA2Terms(): Set<string> {
  const terms = new Set<string>();
  for (const f of readdirSync(EN_DIR)) {
    if (!f.startsWith('a2-') || !f.endsWith('.yaml')) continue;
    const text = readFileSync(join(EN_DIR, f), 'utf8');
    for (const m of text.matchAll(/^\s+term:\s*(.+)\s*$/gm)) {
      terms.add(m[1].replace(/^['"]/, '').replace(/['"]$/, ''));
    }
  }
  return terms;
}
```

test.describe('fr-FR A2 review session', () => {
  test.beforeEach(async ({ page }) => {
    // Schedule every A1 card a year out so the SESSION_SIZE=15 slice is drawn
