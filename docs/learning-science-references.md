# Learning-Science References

The evidence behind intent.md principle 1 ("learning mechanism over decoration"). When a feature claims to strengthen learning, it should cite a **Tier 1** source here, and add one if it isn't listed yet.

Sources are tiered by how much weight a design decision can put on them. Prefer primary research over syntheses, and syntheses over secondary summaries.

## Tier 3: checklists, not sources

Uncited syntheses, such as AI-generated "evidence-based learning system" briefs, are useful only for finding gaps. Trace any claim back to Tier 1 before acting on it. The 2026-10-04 gap review of one such brief produced spec L10–L12. It rejected:

- **Gamification** ("level-up", tokens): an intent.md non-goal, and the evidence for it is weak and mixed.
- **AI tutoring and real-time learner profiles**: break intent principles P3 (zero surveillance) and P5 (static), and non-goal NG7. SM-2 already adapts locally.
- **Hard mastery gating**: replaced with soft recommendations (L12), because locking content adds the kind of friction intent §2 says Fragmented-Time Fiona can't tolerate.
- Two factual errors in that brief: it described dual coding as "visual + auditory" (that is the modality effect), and claimed it "increases working memory capacity".
